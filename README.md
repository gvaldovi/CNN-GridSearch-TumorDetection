# CNN-GridSearch-TumorDetection
Contiene el desarrollo y la evaluación de modelos de Redes Neuronales Convolucionales (CNN) diseñados para la detección automatizada de tumores cerebrales a partir de imágenes de Resonancia Magnética (MRI). El enfoque principal es la optimización sistemática de hiperparámetros para garantizar el máximo rendimiento diagnóstico.
